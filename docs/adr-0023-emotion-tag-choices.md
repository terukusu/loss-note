# ADR-0023: 心理のタグの選択肢に出さないものを、利用者ごとの別の文書に「出さない」集合で持つ

- 状態: 採用
- 日付: 2026-11-24
- 関連: 設計書 C55・4.5・9.2・9.4、ADR-0022（心理のタグの保存の形）、ADR-0012（口座。設定の文書の扱い）、Issue #156・#162・#163・#185

## 背景

心理のタグ（C55。21 個）を付けるシート（保存の後・詳細）で、自分に当てはまらない言葉まで毎回並ぶと、選ぶのを飛ばして ［あとで］ を押すようになる。設定で「選択肢に出すタグ」を選べるようにしたい（#163）。オーナーからすべての判断を任された（2026-11-24）。

決めることは 3 つ。

1. 設定をどこに持つか（端末か、サーバーか。サーバーならどの文書か）
2. 何を持つか（出すタグか、出さないタグか）
3. 出さないにしたタグが付いている取引と、平常心をどう扱うか

## 決定

1. **サーバーの利用者ごとの別の文書** `users/{uid}/settings/emotionTags` = `{hidden: [タグの ID], updatedAt}`。入口は `GET` / `PUT /api/settings/emotion-tags`（本文・応答 `{hidden}`。丸ごと置き換える）。スマホで記録して PC で振り返るので、端末をまたいでそろえる（テーマのような端末の好みではない）。設定の文書 `current` に鍵を足さないのは、`PUT /api/settings` がこの文書を値で組み直して置き換える（知らない鍵を落とす）作りで、前の版へ戻した後に設定を保存すると消えるため
2. **持つのは「出さない」集合**。後の版でアプリがタグを足したとき、設定し直さなくても既定で出る。応答は一覧の順に並べ、読むときに平常心・知らない ID（後の版で足したタグを出さないにした後で前の版へ戻した場合）を落とす。書くときは知らない ID・重複・平常心・配列でない値を 400 で拒み、何も書かない
3. **平常心は出さないにできない**（気づきの「心理ごとの規律」の基準の行。付けられないと「計画どおりに動けた」を残す手段が無くなる）。**記録は変えない**: 出さないにしたタグが付いた取引のタグ・詳細のカード・気づきの集計・期間の取引はそのまま。シートは、開いたときに付いていたタグを出さない設定でも並べる（外せるように。外してもシートを閉じるまで並びに残る）。`PUT /api/trade-emotions` は設定を見ない（選択肢の絞り込みは画面の側だけ）
4. **読めないときはすべて出す**。シートを開く画面（記録する・詳細）は開くたびに設定を読み、読み込み中・失敗の間は絞らない（付けたい心理が無くて付けられないより、多いほうを選ぶ）

## 選択肢

- **端末（localStorage）に持つ**: 端末ごとに設定し直すことになり、スマホと PC で選択肢が食い違う。採らない
- **設定の文書 `current` に鍵を足す**: `PUT /api/settings` の組み立てを直せば今の版では保てるが、前の版の API へ戻した後に設定を保存すると消える。前の版でも消えない別の文書にする。採らない
- **「出す」集合を持つ**: アプリがタグを足したとき、利用者が設定し直すまで新しいタグが出ない。採らない
- **出さないタグを取引から外す・集計から外す**: 過去の記録の意味が変わる（ADR-0022 の決定 4）。採らない

## 結果

- 取引の文書・応答の形と、判定・R・集計は変わらない（ADR-0022 の結果のとおり、#163 は画面の側の絞り込み）
- 前の版へ `rollback.yml` で戻しても、設定の文書は残る（前の版は読まないので全部出るだけ。戻し直せば効く）。`infra/README.md` の切り戻しの注意に足すことは無い
- Firestore の索引・ルールは変えない（API だけが読み書きする。ルールはすべて拒否のまま）
