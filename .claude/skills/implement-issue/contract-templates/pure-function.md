# 契約テンプレ: 純関数（損益・為替換算・集計など）

対象: 副作用を持たず、同じ入力に対して常に同じ値を返す関数。例: 1 トレードの損益、外貨建ての円換算、期間・銘柄・損失種別ごとの集計（件数・合計・平均・勝率・最大の負け）、元データの行の正規化（空欄・「-」・「〃」の扱い）。

DOM・通信（`fetch`・スプレッドシートの API）・現在時刻（`Date.now()` / `new Date()`）・乱数（`Math.random()`）・保存（`localStorage` 等）が混ざっている関数は、**それらを引数で受ける形に分けてから**、計算部分にこのテンプレを使う（画面部品なら `ui-component.md`）。

## 記入項目

| 項目 | 書き方 | 例 |
|---|---|---|
| シグネチャ | 引数と戻り値の型 | `pnl(trade: Trade): number` |
| 単位 | 各引数・戻り値の単位を明記する（`CLAUDE.md`「数値の約束」） | 損益は円、価格は銘柄の建値の通貨、為替は 円 / 外貨（円建てなら 1） |
| 定義域 (pre) | 呼び出し側が保証すべき条件と、破られたときの挙動 | `数量 > 0`、`side ∈ {L, S}` / 決済が空欄なら未決済として `null`（0 にしない） |
| 事後条件 (post) | 戻り値が満たす性質を **入力との関係** で書く | L: `(C − イン) × 数量 × 為替`、S: その符号を反転 |
| 不変条件・性質 | 常に成り立つ性質（性質テストにする） | L と S で符号が逆、数量に対して線形、集計の合計 = 個別の和 |
| 欠損値 | 空欄・「-」・「〃」の扱い | LC が「-」なら LC なしとして扱う / 「〃」は直前の行の値を引き継ぐ（正規化で解決し、計算には持ち込まない） |
| 精度 | 丸めの位置と許容誤差 | 円は計算の最後に 1 回だけ丸める（途中で丸めない）/ 比較は 1 円 |
| 性能 | 呼ばれる頻度と予算 | 1 万行の集計で < x ms |
| 純粋性 | I/O・現在時刻・乱数・グローバル状態を触らない | 「今日」は引数で受ける |
