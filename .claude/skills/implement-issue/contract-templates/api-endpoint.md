# 契約テンプレ: API・データの読み書きの入口

対象: サーバーのエンドポイント、または元データ（Google スプレッドシート等）を読み書きする入口の関数。

判定・変換のロジック（行の正規化、入力の検証）は外部を呼ぶ部分から切り出し、純粋な関数としてテストで固定する（`pure-function.md`）。外部を呼ぶ部分は偽の実装（合成のデータを返すもの）でテストする。

## 記入項目

| 項目 | 書き方 |
|---|---|
| 入口 | メソッド・パス（`GET /api/trades` など）、または関数のシグネチャ |
| 入力 | パラメータとその検証（形式違いは 400 等）。想定外の入力の扱い。**入力値を応答・ログにそのまま出さない** |
| 認証 | 誰が呼べるか。資格情報の受け取り方（環境変数・Secret の参照。値はリポジトリに書かない） |
| 読むもの / 書くもの | 元データのどのタブ・列を読むか / 書くか。**書き込みは計画で合意したものだけ**で、上書き・削除の範囲を明記する |
| 外部への負荷 | 呼び出しの回数・クォータ、キャッシュ、連打制限 |
| 応答 | ステータス、`Content-Type`、JSON の形。後方互換が要る消費者 |
| 異常系 | 外部の失敗・タイムアウト・クォータ超過で何を返すか。例外本文を応答に出さない |
| ログ | 構造化ログ。個人情報・資格情報・実際の売買の記録の中身を出さない |
| 性能 | 応答時間の目安 |
