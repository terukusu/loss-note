# ADR-0007: 取引を消す [元に戻す] は、画面で隠して取り消しの時間の後に削除を送る

- 状態: 採用
- 日付: 2026-11-18
- 関連: Issue #9（取引の一覧と詳細の画面）、EPIC #10（終了条件 13）、設計書 9.1、`docs/ui-guidelines.md` P4、ADR-0004（記録の API・保存の形）、ADR-0006（取引の削除でチャートも消える）

## 背景

取り消せる操作は確認を挟まず、[元に戻す] で戻す（P4・設計書 9.1）。取引を消したら、[元に戻す] で **同じ ID・同じチャート** の取引として戻したい（Issue #9 AC-6）。API の `DELETE /api/trades/{id}` は取引と 2 枠のチャートを 1 つのトランザクションで消す（ADR-0006 決定 3）ので、送った後に同じ取引を作り直すことはできない。

## 決定

1. **画面で DELETE を遅らせる**。[消す] は確認を挟まずに、その取引をアプリの中の「消した印」に入れて一覧・ホーム・詳細・直すから隠し、トースト「<銘柄 L / S 月/日> を消しました」と [元に戻す] を出す。移った先の画面では [元に戻す] にフォーカスを置く（キーで 8 秒の間に届く）。[元に戻す]・閉じるの後は見出しへフォーカスを戻す。DELETE は取り消しの時間（**8 秒**）が過ぎてから 1 回だけ送る（`ui/src/lib/deletions.ts`）
2. **[元に戻す] は印を外すだけ**（要求を送らない）。保存先では何も変わっていないので、同じ ID・同じチャートのまま戻る
3. **トーストはアプリの殻に 1 つ**（`Shell` の差し込み口）。画面を移っても残り、[元に戻す] で戻せる。同時に待つ削除は 1 件で、次の [消す] で前の削除はすぐ送る
4. **時間を止める・すぐ送る**: トーストにフォーカス・ポインタがある間は時間を止め、離れたら 8 秒を置き直す（WCAG 2.2.1）。ログアウトの前・タブが隠れた（`visibilitychange` の hidden・`pagehide`）・トーストを閉じたときは、待っている削除をすぐ送る（`keepalive`）
5. **結果の扱い**: 送り始めたら [元に戻す] のトーストは閉じる（応答を待つ間に、効かない [元に戻す] を出さない）。DELETE が 204 / 404 なら消えたまま（このセッションの間は隠す）。ほかの失敗は印を外して戻し、「消せませんでした。もう一度 [消す] を押してください」を **別の知らせ**（role="alert"。応答の本文は出さない）で出す。次に消した取引の [元に戻す] は置き換えず、失敗の知らせを閉じても待っている削除は送らない
6. **ログアウト**: 待っている削除を送ってからログアウトし、その後に印と知らせを空にする（次の利用者に前の利用者の知らせを見せない）
7. 保存の形・API は変えない

## 選択肢

- **論理削除（取引の文書に「消した」の印を足す）**: 保存の形・API のすべての入口（一覧・詳細・直す・チャート）に印の扱いが要り、消したはずの個人の記録が保存先に残り続ける。いつ本当に消すかの決まり（掃除の仕組み・期間）が要り、オーナーの判断になる。採らない
- **消す文書を別の場所へ退避し、戻す入口を足す**: 同じく保存先に残り、API の入口と ADR-0006 決定 3（取引とチャートを 1 つのトランザクションで消す）が変わる。採らない
- **消す前に画像を読んでおき、[元に戻す] で作り直す**: ID が変わる（AC-6 に反する）。作り直しが失敗すると記録が失われる。採らない

## 結果

- 保存の形・API を変えずに、同じ ID・同じチャートで戻せる。消した取引は時間の後に保存先から本当に消える（残り続けない）
- **代償（倒れる向き）**: 取り消しの時間の間にタブを閉じる・端末が落ちる・通信が切れると、DELETE が届かず取引が **残る**（消える側には倒れない。記録は失われない）。次に開くと一覧にあり、もう一度消せる。`keepalive` と `visibilitychange` / `pagehide` の送り出しで届きやすくはするが、保証はしない
- **取り消しの時間の間の再読み込み**: アプリの中で開いた詳細の URL（リンク・戻る / 進む）は、取り消しの時間の間も「この取引は見つかりません」。再読み込みは新しいページなので、`visibilitychange` で先に送った削除と新しいページの読みの届く順は保証しない（取引がまだ出ることがある）。時間が過ぎて DELETE が届いた後は、直接開いても見つからない（Issue #9 AC-5 の読み方。main の決定 2026-11-18）
- 記録する画面の開いたときの既定（最後に記録した取引の銘柄・数量）は、取り消しの時間の 8 秒の間だけ、消した印の取引も数える（直さない）
- 確かめ: `tests/ui/deletions.test.ts`（偽の時計: 8 秒・[元に戻す]・hold / resume・次の [消す]・flush・失敗で戻る・404 は消えたまま）、`tests/ui/trade-screens-view.test.tsx`（X1 → X2）、`npm run ui:check` の T-X1（確認の画面が 0 件・一覧 N → N − 1・アプリの中で開くと見つからない・8 秒後に DELETE 1 回・再読み込みでも見つからない）と T-X2（DELETE を送らず同じ ID・B・2 枚のチャート）
- 銘柄を消す・チャートの差し替え / 外す・直した後の [元に戻す]（別 Issue）は、同じ部品（`Toast`）を使う。保存先で戻せる操作（差し替えの前の画像を持つなど）は、その Issue で方式を決める
