# 契約テンプレ: 画面部品・操作

対象: 画面の部品と操作。例: トレードの一覧、1 トレードの入力・編集、気づきの一覧、集計の表・グラフ、絞り込み（期間・銘柄・損失種別）、保存。

画面部品は DOM と描画が本体なので、**表示する値の計算・整形は DOM を持たない関数に切り出し**（そちらは `pure-function.md`）、この契約では「何を入力に、何をどう表示し、どの操作に何が起きるか」を書く。

## 記入項目

| 項目 | 書き方 |
|---|---|
| 入力 | 部品が受け取る状態（トレード・気づき・マスタ・絞り込み・設定）と、その出どころ（元データ / 計算 / 利用者の操作） |
| 表示 | 何をどの単位・桁で出すか（円の桁区切り、損益の符号と色、色だけに頼らず符号・ラベルを添える） |
| 操作 | マウス・キー・タッチと、それぞれで状態がどう変わるか。削除・上書きなど戻せる操作は確認を出さず [元に戻す] で戻す |
| 状態と保存 | 状態の持ち場所。保存するなら形式と後方互換（古い形式を読めるか） |
| 異常系 | データが無い・読み込みに失敗・入力が範囲外のときの表示（入力値をそのまま HTML として出さない） |
| セキュリティ | DOM への値の入れ方（`textContent` / 属性の setter。`innerHTML` にデータを入れない） |
| 性能 | 描き直しの予算（行数の想定とあわせて） |
| 画面幅 | 幅 360px で横スクロールが出ないこと、スマホでの列の絞り込み・切替 |
| アクセシビリティ | キーボードで操作できるか、ラベル・読み上げの名前、コントラスト |
| 設計との対応 | 設計書の節・ADR |
